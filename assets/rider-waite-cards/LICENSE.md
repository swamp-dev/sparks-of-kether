# Rider-Waite-Smith card asset licensing

The 22 major arcana JPEGs in this directory are **unmodified downloads
from Wikimedia Commons** of a 1910 "Pam-A" printing of the tarot deck
drawn by Pamela Colman Smith under the direction of A. E. Waite and
first published by William Rider & Son, London, in December 1909. The
Commons set is "Rider-Waite-Smith tarot deck (TaionWC)", sourced from
scans at <http://muzendo.jp/blog/>.

Every file is byte-identical to the Commons original; the SHA-1 in the
table below is the one the Commons `imageinfo` API reports, so provenance
can be re-verified at any time:

```bash
sha1sum assets/rider-waite-cards/*.jpg
```

## Why these are free to use

- **United States:** published 1909/1910, i.e. before 1931, so the
  artwork is in the public domain regardless of any renewal history.
- **UK / EU / life+70 jurisdictions:** the last surviving author,
  Pamela Colman Smith, died in 1951; the work entered the public domain
  on 2022-01-01.
- **The scans themselves** add no new copyright: faithful reproductions
  of public-domain 2D works are unprotected in the US (*Bridgeman Art
  Library v. Corel*) and the EU (Directive 2019/790, Art. 14). Commons
  tags the files `PD-old-80-expired` and `CC-PD-Mark`.

## What is NOT covered (do not swap these in)

- **US Games Systems' 1971 recolour** and its later variants (Universal
  Waite, Radiant Rider-Waite, Centennial, etc.). US Games claims
  copyright in those colourings, card backs and boxes. The previous
  contents of this folder were 199×340 JPEGs of unknown origin whose
  colourway matched the 1971 edition; they were removed in #369.
- **The "Rider-Waite" and "Rider" trademarks**, held by US Games. Use
  "Waite-Smith" or "Smith-Waite" in any product-facing copy; naming the
  source in a credits line is fine.
- **Tarot de Marseille modern editions:** the 1930 Grimaud / Paul
  Marteau recolour, the 1997 Camoin-Jodorowsky restoration, the Flornoy
  restorations, and the CBD Tarot (Creative Commons, non-commercial
  only) are all encumbered. If a Marseille look is ever wanted, use the
  Jean Dodal (1701-1715) or Nicolas Conver (1760) scans on Wikimedia
  Commons / BnF Gallica, which are public domain on the same basis as
  the files here.

## Runtime use

Nothing in the app references this folder yet. These are **source
assets** (~0.7–1.1 MB each, 1200 DPI scans). When a component first
consumes them, derive sized WebPs into `public/` with the same
`ffmpeg` recipe as `assets/portraits/LICENSE.md` and keep the originals
here untouched so the SHA-1 table stays valid.

## Alternative set

Commons also hosts the 1909 first printing ("Roses & Lilies" back,
category "Rider-Waite tarot deck (Roses & Lilies)", files
`RWS1909 - NN <Name>.jpeg`, ~830×1430, scanned by Saskia Jansen). It is
public domain on the same basis and is the one to reach for if the
exact 1909 edition ever matters more than resolution.
